# Trabalho_1
Desenvolver um site institucional para uma organização educacional fictícia ou real (escola, universidade, ONG educacional, etc.) utilizando apenas HTML5 semântico. O foco é na estruturação correta do conteúdo, uso apropriado de tags semânticas e acessibilidade.
# Trabalho 01 - Site Institucional com HTML Semântico

Projeto acadêmico desenvolvido utilizando HTML5 semântico.

## Estrutura
- index.html
- sobre.html
- cursos.html
- contato.html

## Recursos utilizados
- Tags semânticas do HTML5
- Formulários com validação
- Tabelas
- Imagens com acessibilidade
